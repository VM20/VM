The indexOf() method in JavaScript is used to find the first occurrence of a specified value in an array. If the value is found, it returns the index (position); if not, it returns -1. array.indexOf(searchElement, fromIndex)

  • SearchElement: The item you're searching for.
  • fromIndex (optional): The index to start the search from (default is 0).

Example var fruits = ["apple", "banana", "mango", "apple", "orange"]; console.log(fruits.indexOf("apple")); // 0 (first occurrence) console.log(fruits.indexOf("orange")); // 4 console.log(fruits.indexOf("grape")); // -1 (not found)

Here’s a polyfill for Array.prototype.indexOf, which adds support for indexOf in older JavaScript environments (like IE8 and earlier) where it doesn't exist.

Just include this code at the top of your JavaScript file. It checks if indexOf doesn't exist and defines it if needed — so it won't overwrite modern browser implementations.

if (!Array.prototype.indexOf) { Array.prototype.indexOf = function(searchElement, fromIndex) { if (this == null) { throw new TypeError('"this" is null or not defined'); } var length = this.length >>> 0; // Ensure length is a positive integer fromIndex = +fromIndex || 0; if (Math.abs(fromIndex) === Infinity) { fromIndex = 0; } if (fromIndex < 0) { fromIndex = Math.max(length + fromIndex, 0); } for (var i = fromIndex; i < length; i++) { if (i in this && this[i] === searchElement) { return i; } } return -1; }; }
