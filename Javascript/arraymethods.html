JavaScript Array Methods with Examples

🔁 Iteration Methods

  • forEach(callback) – Executes a function for each element.
    [1, 2, 3].forEach(x => console.log(x))
  • map(callback) – Creates a new array by transforming each element.
    [1, 2, 3].map(x => x * 2) → [2, 4, 6]
  • filter(callback) – Filters elements that match a condition.
    [1, 2, 3, 4].filter(x => x % 2 === 0) → [2, 4]
  • reduce(callback, initialValue) – Reduces to a single value.
    [1, 2, 3].reduce((a, b) => a + b, 0) → 6
  • find(callback) – Finds the first matching element.
    [1, 2, 3].find(x => x > 1) → 2
  • findIndex(callback) – Finds the index of the first match.
    [1, 2, 3].findIndex(x => x === 2) → 1
  • some(callback) – Checks if any element passes a condition.
    [1, 2, 3].some(x => x > 2) → true
  • every(callback) – Checks if all elements pass a condition.
    [1, 2, 3].every(x => x > 0) → true

🛠️ Modifying Arrays

  • push(item) – Add item(s) to end.
    let arr = [1, 2]; arr.push(3) → [1, 2, 3]
  • pop() – Remove last item.
    let arr = [1, 2, 3]; arr.pop() → [1, 2]
  • unshift(item) – Add item(s) to beginning.
    let arr = [2, 3]; arr.unshift(1) → [1, 2, 3]
  • shift() – Remove first item.
    let arr = [1, 2, 3]; arr.shift() → [2, 3]
  • splice(start, deleteCount, ...items) – Add/remove items.
    let arr = [1, 2, 3]; arr.splice(1, 1, 4) → [1, 4, 3]
  • sort(compareFunction) – Sort array in place.
    [3, 1, 2].sort() → [1, 2, 3]
  • reverse() – Reverse array in place.
    [1, 2, 3].reverse() → [3, 2, 1]
  • fill(value, start, end) – Fill part of array.
    [1, 2, 3].fill(0, 1, 3) → [1, 0, 0]
  • copyWithin(target, start, end) – Copy elements within array.
    [1, 2, 3, 4].copyWithin(0, 2, 4) → [3, 4, 3, 4]

🧱 Creating & Combining Arrays

  • concat(...arrays) – Merge arrays.
    [1, 2].concat([3, 4]) → [1, 2, 3, 4]
  • slice(start, end) – Get a portion of the array.
    [1, 2, 3, 4].slice(1, 3) → [2, 3]
  • flat(depth) – Flatten nested arrays.
    [1, [2, [3]]].flat(2) → [1, 2, 3]
  • flatMap(callback) – Map and flatten the array.
    [1, 2].flatMap(x => [x, x * 2]) → [1, 2, 2, 4]
  • join() — Convert array to string
    [1, 2, 3].join('-') → "1-2-3"
  • flat() — Flatten nested arrays
    [1, [2, [3]]].flat(2) → [1, 2, 3]
  • toReversed() — Return a reversed copy (ES2023+)
    [1, 2, 3].toReversed() → [3, 2, 1]

  • indexOf(value) – First index of value.
    [1, 2, 3, 2].indexOf(2) → 1
  • lastIndexOf(value) – Last index of value.

🧾 Utility Methods

  • Array.isArray(value) – Check if value is an array.
    Array.isArray([1, 2, 3]) → true
  • join(separator) – Join elements into a string.
    [1, 2, 3].join("-") → "1-2-3"
  • toString() – Convert array to string.
    [1, 2, 3].toString() → "1,2,3"
  • length — Property: number of elements
    [1, 2, 3].length → 3
  • Array.isArray() — Check if a value is an array
    Array.isArray([1, 2]) → true
  • fill() — Fill array with a static value
    [1, 2, 3].fill(0) → [0, 0, 0]
  • from() — Create array from array-like or iterable
    Array.from('abc') → ['a', 'b', 'c']
  • of() — Create array from arguments
    Array.of(1, 2, 3) → [1, 2, 3]
  • at() — Access by index (supports negative indices)
    [1, 2, 3].at(-1) → 3
  • keys(), values(), entries() — Get iterators for array contents
    [...[1, 2].keys()] → [0, 1]
    [...[1, 2].values()] → [1, 2]
    [...[1, 2].entries()] → [[0, 1], [1, 2]]

JavaScript Array Methods

let arr = [1, 2, 3];

// Add to end
arr.push(4); // [1, 2, 3, 4]

// Remove from end
arr.pop(); // [1, 2, 3]

// Add to beginning
arr.unshift(0); // [0, 1, 2, 3]

// Remove from beginning
arr.shift(); // [1, 2, 3]

// Add/remove at specific index
arr.splice(1, 1, 9); // [1, 9, 3] — remove 1 item at index 1, insert 9

// Extract sub-array (non-destructive)
arr.slice(0, 2); // [1, 9]

✅ What concat Does

concat() is a built-in method that:

  • Belongs to the Array prototype
  • Returns a new array
  • Combines (concatenates) the calling array with one or more arrays or values
  • Does not modify the original arrays

array1.concat(array2, array3, ..., arrayN)

const a = [1, 2];
const b = [3, 4];
const result = a.concat(b);

console.log(result); // [1, 2, 3, 4]

Term Description
Method A function attached to an object (like concat is to Array)
Prototype Method Defined on Array.prototype so all arrays inherit it
Immutable Returns a new array; doesn’t change the original
✅ Combining Arrays: concat() vs Spread Operator

const a = [1, 2, 3];
const b = [4, 5, 6];

const combined = a.concat(b);
// or using spread operator:
const combined2 = [...a, ...b];

console.log(combined); // [1, 2, 3, 4, 5, 6]
console.log(combined2); // [1, 2, 3, 4, 5, 6]

✅ Summing Two Arrays Element-Wise

const a = [1, 2, 3];
const b = [4, 5, 6];

const sum = a.map((val, index) => val + b[index]);

console.log(sum); // [5, 7, 9]

✅ Zip and Add with Different Lengths (Safe Version)

const a = [1, 2, 3];
const b = [4, 5];

const maxLength = Math.max(a.length, b.length);
const result = Array.from({ length: maxLength }, (_, i) => (a[i] || 0) + (b[i] || 0));

console.log(result); // [5, 7, 3]

✅ Combine Arrays and Remove Duplicates

const a = [1, 2, 3];
const b = [2, 3, 4, 5];

// Combine + Remove Duplicates using Set
const unique = [...new Set([...a, ...b])];

console.log(unique); // [1, 2, 3, 4, 5]

How It Works

  • [...] spreads the arrays.
  • new Set() removes duplicate values (because Set only stores unique items).
  • Another [...] spreads the Set back into an array.
✅ Sum Arrays and Get Unique Results | Remove Duplicates After Element-wise Addition

const a = [1, 2, 3];
const b = [3, 2, 1];

const sum = a.map((val, i) => val + (b[i] || 0)); // [4, 4, 4]
const uniqueSum = [...new Set(sum)];

console.log(uniqueSum); // [4]
